The problem

Diligence that doesn't scale with deal volume

Fernbrook's private-credit team underwrites middle-market loans, which means reading credit agreements. 200 to 400 pages of covenants, definitions, and cross-references, each one different from the last. Before Meridian, that reading was done by junior analysts, manually, against a checklist, at night, because daytime was for calls.

The team wasn't short on rigor. They were short on hours. Deal volume had grown faster than headcount, and the bottleneck wasn't sourcing deals. It was reading them fast enough to act on them.

Off-the-shelf AI tools weren't an option. A hallucinated covenant in an investment memo isn't a minor bug; it's the kind of error that ends up in a lawsuit. Any system Fernbrook adopted had to be more careful than the analysts it was assisting, not less.

The non-negotiable requirement Every claim the system makes has to be traceable to the exact page and passage it came from. "Trust me" was never going to be acceptable to an investment committee.

Constraints

Where zero tolerance actually meant zero

This is a category where "usually right" isn't a product, it's a liability.

  • No ungrounded claims. Every extracted fact needed a citation back to the source document. Enforced in code, not just in the prompt.
  • Confidence had to be honest. A model that's uncertain must say so and route to a human, not guess fluently.
  • Existing deal-room integration. Analysts already lived in a specific document workflow; we had to fit into it, not replace it.
  • Auditability for compliance. Every decision. Automated or escalated. Needed a permanent, reviewable log.

The approach

Retrieval first, generation last, humans always

Every claim the system makes is grounded in a retrieved passage and linked back to the page it came from.

Pipeline

Extraction is boring on purpose

Documents are parsed, chunked, and embedded into pgvector on ingest. When an analyst asks a question. "what's the leverage covenant?". The system retrieves the actual relevant passages first, and only then asks a model to synthesize an answer from what it was just shown. It is never allowed to answer from memory.

The confidence gate

Nothing ships without a citation, ever

The assertion below isn't a style choice, it's the whole safety model. If the draft can't cite its source, the code refuses to return it. Below a 0.95 confidence score, the work routes to a human. And that routing decision is logged, so an auditor can later see exactly why a document needed review.

async def review_covenant(doc: Document):
    passages = await retrieve(doc, top_k=12)
    draft = await agent.run(doc, passages)

    # Nothing ships without a citation.
    assert draft.citations, "ungrounded output"

    if draft.confidence < 0.95:
        return to_human(draft, reason="low_conf")
    return finalize(draft, audit=True)

Results

Four months into production

First-pass review of a new credit agreement now takes hours, not nights. Analysts still read every document. The system hasn't replaced their judgment. But they're reading a structured summary with every claim already sourced, instead of starting from a blank page at 11 p.m.

The number Fernbrook's CTO cares about most isn't the speed. It's that in four months of live deals, zero cited claims have turned out to be wrong. The confidence gate routes roughly one document in fourteen to a human, and that number is trusted precisely because it's honest about its own limits.
